# Camera Lighting Setup Guide

Phase 10CのCOUNT-UP自動判定では、ダーツ本体と影の差分を分離しやすい照明が必要です。

## 推奨配置

- 盤面の正面から左右均等に拡散光を当てる
- 片側だけの強い照明を避ける
- 盤面上の白飛び、黒つぶれ、強い反射を避ける
- ダーツの影が隣セグメントへ大きく伸びる場合は照明位置を下げるか拡散する
- カメラは盤面へできるだけ正対させ、盤面リングが円に見える位置へ置く

## 診断値の目安

- `quality = good`: 自動判定向き
- `quality = acceptable`: 手動補正を併用しながら利用可能
- `quality = poor`: 照明変更を推奨
- `shadowRisk` が高い場合は、左右差・上下差・白飛びのどれかが強い状態

## 現地確認

1. `/camera/home` からカメラPC単体モードを開く
2. Calibrationを保存する
3. 照明診断を5秒程度実行する
4. `quality` と `shadowRisk` を確認する
5. S11、S16、BULL付近へ各10投以上投げ、候補JSONを記録する
6. 影が第一候補になる場合は、照明を拡散して再測定する

画像本体、base64、動画は診断JSONへ保存しません。
