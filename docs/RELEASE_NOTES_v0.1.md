# Release Notes v0.1

DartsSupportApp MVP v0.1 は、iPhone Expo Goで主要導線を確認するためのプロトタイプ版です。

## Version

- App: `DartsSupportApp`
- package.json: `0.1.0`
- app.json: `0.1.0`
- schemaVersion: `9`

## 実装済み機能

- 初期設定
- ホーム
- 練習メニューDB
- おすすめ練習ロジック
- 練習メニュー詳細
- お気に入り練習
- 練習記録の入力/一覧/詳細/編集/削除
- 写真スコア記録MVP
- 写真スコア基準画像登録/品質評価
- メニュー別記録履歴
- 分析ダッシュボード
- フォーム相談
- 相談履歴保存/一覧/詳細/削除
- 資料ライブラリ検索
- 資料詳細
- AsyncStorage ローカル保存
- schemaVersion 9 migration
- TypeScript / ESLint / Prettier / test / data integrity check
- GitHub Actions CI

## 既知の制限

- 公式API連携なし
- AI API連携なし
- ログインなし
- クラウド同期なし
- 端末間データ移行なし
- 本番向けバックアップなし
- グラフはViewベースの簡易表示
- 相談回答は固定ロジック
- 資料本文はプロトタイプ用の一般化した内容
- 医療的な診断や治療目的の機能なし

## 注意

- DARTSLIVE / PHOENIX の公式ロゴ、公式画像、公式APIは使用していません。
- 機種名は文字ラベルとしてのみ使用しています。
- イップス関連の文言は不安を煽らないよう、休養や専門家相談も選択肢として表現しています。

## v0.1 実機確認の重点

- 初期設定からホームまでの流れ
- 練習メニュー選択から記録保存までの流れ
- 記録保存後に分析へ反映されること
- フォーム相談の回答と履歴保存
- 相談履歴から練習/資料へ遷移できること
- 資料ライブラリ検索が使えること
- 0件状態でクラッシュしないこと
