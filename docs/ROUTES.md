## 共通導線

- PC Web TopNavigation: `/home`, `/game`, `/account/profile`
- BottomNav: Expo Goと1024px未満のWebで `/home`, `/practice`, `/records`, `/analysis`, `/consult`
- 詳細画面は一覧または関連元へ戻るボタンを持つ
- 危険操作は確認ダイアログと赤系ボタンを使う
- プレイ中のゲーム画面はBottomNavを非表示にし、戻る操作は一時停止、継続、途中終了の確認を通す
- 進行中ゲームの復元先は `game_sessions.mode` と `matches` を優先し、COUNT-UPは `/game/count-up/[gameId]`、01は `/game/01/[gameId]`、CRICKETは `/game/cricket/[gameId]`、MATCHは `/game/match/[matchId]` へ戻す
- Account未登録を理由にCOUNT-UP/01/CRICKETの開始を禁止しない
- Account登録画面では、現在の登録が端末内Rating所有者識別用であり、クラウド同期・本人確認は未対応であることを表示する
- Rating対象表示はAccount、OWNER紐付け、初回3MATCH確定、GAME開始日時に基づく。COUNT-UPは常にRating対象外
- Rating Engine v2はpending Evaluationを起動時、Home/Game Hub/Account Rating focus時に処理し、SnapshotとProfileを同一transactionで更新する
- 単独01は01 Indexだけ、単独CRICKETはCricket Indexだけを更新し、単独ゲームでMatch Indexは変更しない
- Accountプロフィール画面では共通Account IDと `darts_common_data` v1を表示するが、Export / Import実行やDartsSupportApp通信は提供しない
- CRICKETは全7ターゲットCLOSE済みでも0点なら自然終了せず、1点以上または15R到達まで継続する
- MATCHはGAME1 501/701、GAME2 STANDARD CRICKET、1勝1敗時のみGAME3 CHOICE、先に2勝したプレイヤーを勝者にする
- MATCH内CRICKETは全7ターゲットCLOSE済みでも0点なら自然勝利せず、1点以上または15R到達まで継続する
- 1024px以上のPC Webではゲームプレイ画面を横長2カラムにし、スコア/状態と入力/操作を分ける。Expo Goと狭幅Webでは既存の縦積みUIを維持する
- Rating履歴の専用画面、効果音・アワード動画はPhase 9の対象外
