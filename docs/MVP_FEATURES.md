# MVP Features

DartsSupportApp MVP v0.1 で確認できる機能一覧です。

## 初期設定

- レーティング入力
- レベル自動判定
  - 初級: RT1-5
  - 中級: RT6-9
  - 上級: RT10以上
- 利用機種選択
  - DARTSLIVE
  - PHOENIX
  - 両方
- 主な悩みの複数選択
- 設定再編集

## 練習メニュー

- 24件の練習メニューDB
- レベル、機種、ゲーム種別、悩みタグで絞り込み
- 練習詳細
- 練習メニュー別の記録履歴
- お気に入り保存
- おすすめ練習表示

## 練習記録

- 記録入力
- 練習メニュー検索/選択
- 手入力メニュー名
- 写真スコア記録
  - 空のボード基準画像登録
  - 基準画像と現在画像のキャリブレーション品質評価
  - 中心ズレ、外周半径差、20方向の角度差の警告
  - 基準画像比較候補の差し替え可能な入口
  - 実ピクセル差分未実装時の単一画像候補β/補助候補フォールバック
  - 自動候補β + 手動補正による候補選択
  - キャリブレーションベース候補
  - 手動タップ追加
  - 候補選択後のドラッグ微調整
  - グルーピング分析と改善アドバイス
  - 実機向けステップ表示、やり直し導線、位置修正導線
- 記録一覧
- 記録詳細
- 記録編集
- 記録削除
- メニュー別記録一覧

## 分析

- 7日/30日/90日/全期間フィルタ
- 練習回数
- COUNT-UP平均
- 平均ブル数
- 平均クリケットマーク数
- ベストスコア
- スコア推移グラフ風UI
- ブル数推移グラフ風UI
- ゲーム別集計
- 調子の割合
- 改善コメント
- 次にやるべき練習

## フォーム相談

- 相談カテゴリ選択
- 深刻度選択
- 悩み入力
- 固定ロジックによる相談回答
- 関連練習メニュー表示
- 関連資料表示
- イップス関連の安全な注意文
- フォーム写真3枚相談
  - 正面、横、リリース後の写真登録
  - 利き手選択
  - 自己チェック入力
  - 直近写真スコア分析との連携
  - スタンス、グリップ、リリース、フォロースルー、体の開き、リズムの固定ロジック助言
  - 画像AI診断ではなく、ユーザー入力と保存済み写真スコアをもとにしたMVP助言
  - 履歴一覧
  - 履歴詳細
  - 履歴削除

## 相談履歴

- 相談結果のローカル保存
- 履歴一覧
- 履歴詳細
- 履歴削除
- 履歴から練習詳細/記録入力/資料詳細へ遷移
- フォーム写真相談履歴の保存、一覧、詳細、削除
