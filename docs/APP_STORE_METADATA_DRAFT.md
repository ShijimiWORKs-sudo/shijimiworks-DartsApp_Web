## App Name

DartsSupportApp

## Subtitle案

ソフトダーツ練習を記録して振り返る

## 説明文案

DartsSupportAppは、ソフトダーツの練習メニュー、練習記録、分析、フォーム相談をiPhoneで確認するための練習支援アプリです。

レーティングや悩みに応じた練習メニューを確認し、COUNT-UP、01、CRICKETなどの記録を端末内に保存できます。保存した記録から、練習回数、平均スコア、ブル数、ゲーム別傾向を見返し、次に取り組む練習を考えやすくします。

フォーム相談は固定ロジックによる一般的なアドバイスで、医療、診断、専門指導の代替ではありません。DARTSLIVE / PHOENIX の公式アプリではなく、公式APIや公式ロゴは使用していません。
