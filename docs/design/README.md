# Design Notes

MVPの初期デザイン資料置き場です。

- iPhone向けの縦長UIを前提にします。
- ダークテーマを基本に、ミントグリーンとブルーをアクセントにします。
- 公式DARTSLIVE / PHOENIXのロゴや画面模写は避け、機種名は選択ラベルとしてのみ扱います。
- MVPの主軸は、練習処方、記録、分析、フォーム相談です。
